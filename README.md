# Student Grades Analysis

Automated grading analysis using Python and Pandas.

## What it does
-Google Sheets API integration

-Data anonymization (Faker)

-Data cleaning (dropna)

-Statistical summary 

-Business insight 

## Tools
Python, Pandas, Google Sheets API

## How to run
1. Open `tax_group_grades_analysis.ipynb` in Google Colab or Jupyter
2. Run all cells
3. Output shows grade distribution, averages, and student groupings

## Note
Student names have been anonymized for privacy.
